# 最寄りまで急げ！

> 終バスと終電を通知するWebアプリ


## デモ
- デモURL：https://kbh-vol8-team-06.vercel.app

## 課題
終電飲み会終わりの方！！飲み会に気が取られて終電を逃してしまうことがありませんか？
## 解決方法
- 終電の30分前、15分前、5分前に通知を送る
- アプリ内に終電までの時間が表示
- その電車・バスを乗りたいかを選択できる

## 使用技術
| 領域           | 技術 |
| -------------- | ---- |
| フロントエンド | React Next.js Tailwind CSS |
| バックエンド   | Typescript Supabase |
| その他         | Vite vercel|

## 動かし方
- `npm install` … 依存をインストールする
- `npm run dev` … 開発サーバを起動（http://localhost:5173）
- `npm run build` … 壊れていないかの確認。PR を出す前に必ず通す
